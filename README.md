# EarthLoop

![TypeScript](https://img.shields.io/badge/TypeScript-5.x-informational)
![Next.js](https://img.shields.io/badge/Next.js-16-black)
![React](https://img.shields.io/badge/React-19-informational)

**EarthLoop** is a sustainability-focused frontend prototype for SMEs, built to explore how carbon-accounting and ESG information can be presented through a modern product experience.

The repository focuses on product UI, responsive frontend architecture, motion, reusable components, and sustainability-oriented content rather than a production carbon-accounting backend.

## Highlights

- Responsive marketing site built with Next.js App Router
- Carbon accounting and ESG dashboard concepts
- Animated product sections with Framer Motion
- Reusable cards, buttons, layout primitives, and navigation
- Blog system backed by structured JSON content
- Login and signup interface prototypes
- Pricing and product-positioning pages
- Custom visual effects and branded sustainability UI

## Tech stack

## Project structure

```text
EarthLoop/
├── app/          App Router pages and blog logic
├── components/   product sections and reusable UI
├── constants/    shared values
├── data/         structured demo/editorial content
├── public/       images, fonts, and brand assets
└── styles/       global styling and animation
```

## Product areas

| Area | What is represented |
| --- | --- |
| Carbon accounting | Utility-data and footprint measurement concepts |
| ESG dashboard | Sustainability KPI and benchmarking concepts |
| Marketing site | Product positioning, pricing, about, contact |
| Blog | Sustainability-oriented editorial demo content |
| Authentication | Login/signup interface prototypes |

## Portfolio scope

EarthLoop is presented as a **frontend/product prototype**. Some sustainability metrics, stories, benchmarking examples, and product claims in the interface are illustrative demo content and should not be interpreted as audited environmental data, regulatory certification, or production analytics.
